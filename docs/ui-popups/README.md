# Ảnh chụp popup — Sobi World (2026-11-16)

Chụp từ bản dev (nhánh `feature-plot-upgrade`), cửa sổ 1600×900, save "max" (`npm run dev:max-save`, mọi khu mở, đầy đồ),
chạy trên sandbox riêng `%TEMP%\sobiworld-popups` (không đụng save thật). 96 ảnh, chia theo khu.

Ghi chú chung cho người chỉnh giao diện:
- Có 2 kiểu khung chính: **cửa sổ lớn** (`c-window`, dải tiêu đề gỗ, nút ✕ hồng góc phải, ví dụ Bộ sưu tập, Cửa hàng)
  và **hộp thoại nhỏ** (`c-dialog`, ví dụ Đổi tên, Xuất chuồng, Ô đất). Mỗi khu dùng lại hai khung này.
- Cửa sổ dùng chung (Menu, Cửa hàng, Kho đồ, Cài đặt…) giống nhau ở mọi khu; chỉ chụp một lần ở thư mục `1-chung`.
- Một vài ảnh là lớp phủ / màn trong trận (thanh kỹ năng, nhãn quái, bong bóng NPC), không phải popup đóng mở, nhưng cùng bộ giao diện nên giữ lại.
